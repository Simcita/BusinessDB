# Code Style

Every function:

Must contain documentation.

Format:

/**
 * function_name()
 * ----------------
 * Description.
 *
 * Parameters:
 * -----------
 * param : type
 *
 * Returns:
 * --------
 * return_type
 */

Use descriptive variable names.

Avoid abbreviations.

Bad:

usr
cfg
tmp

Good:

user_submission
campaign_configuration

Prefer readability over brevity.
